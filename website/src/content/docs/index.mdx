ゲームに CPU 戦を足すと、たいてい `if isAI` が増えます。対戦相手が人間かボットかでコードが分かれ、
リプレイ再生のためにもう一本の経路が生まれます。経路が三本になれば、ルールの修正箇所も三つです。

ebigentserver は、この分岐を最初から作りません。視界を受け取って行動を返すもの、という一点では、
人間もボットも LLM もリプレイストリームも同じ `agent` です。そう決めておけば、ゲームのルールが
「誰が座っているか」を問う必要はありません。切断したプレイヤーの席をボットに引き継ぐ処理も、
特別な機構ではなく、新しい agent の着席として扱えます。
