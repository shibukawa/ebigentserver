ゲームに CPU 戦を足すとき、たいてい `if isAI` が増える。対戦相手が人間かボットかでコードが分岐し、
リプレイ再生のためにもう一本の経路が生え、三本になったところでルールの修正が三箇所必要になる。

ebigentserver はその分岐を最初から禁じる。視界を受け取って行動を返すもの、という一点で人間もボットも
LLM もリプレイストリームも同じ `agent` だと決めてしまえば、ゲームのルールは「誰が座っているか」を
二度と問わなくてよくなる。切断したプレイヤーの席にボットを座らせる処理は、追加の機構ではなく
ただの新しい着席になる。
